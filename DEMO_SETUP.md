## Запуск настройки

### Вариант 1: Через командную строку

1. Установите API ключ:
```bash
export SPICE_API_KEY=your_api_key_here
```

2. Запустите скрипт:
```bash
node setup-demo.js
```

### Вариант 2: Через веб-интерфейс

1. Откройте файл `demo-setup-web.html` в браузере
2. Введите ваш API ключ в поле
3. Нажмите кнопку "Начать настройку"
4. Следите за процессом в логах

## API Endpoints

Скрипт использует следующие API endpoints:

- `POST /ajax_api/login` - авторизация
- `POST /index_api/search` - поиск пользователей  
- `POST /ajax_api/setContact` - добавление в контакты
- `POST /ajax_api/setFriend` - добавление в друзья
- `POST /index_api/match` - создание лайков/матчей

## Troubleshooting

Если скрипт не работает:

1. Проверьте API ключ: `echo $SPICE_API_KEY`
2. Убедитесь что демо-пользователи существуют на сайте
3. Проверьте логи в консоли для диагностики ошибок
