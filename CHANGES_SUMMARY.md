## 🚀 Как использовать

### Консольная версия:
```bash
export SPICE_API_KEY=your_api_key
node setup-demo.js
```

### Веб-версия:
1. Откройте `demo-setup-web.html` в браузере
2. Введите API ключ
3. Запустите настройку

## 🔧 API Endpoints

Используемые endpoints согласно правилам авторизации:
- `POST /ajax_api/login?api_key=${API_KEY}` - авторизация
- `POST /ajax_api/setContact?api_key=${API_KEY}` - контакты
- `POST /ajax_api/setFriend?api_key=${API_KEY}` - друзья  
- `POST /index_api/match?api_key=${API_KEY}` - матчинг
- `POST /index_api/search?api_key=${API_KEY}` - поиск
