## 🎮 Как это работает

### 1. Автоматическая инициализация

При загрузке `discover.html`:

```javascript
// Система автоматически:
1. Загружает дату рождения текущего пользователя
2. Получает профили из API
3. Извлекает даты рождения из профилей
4. Рассчитывает астрологическую совместимость
5. Сортирует профили по убыванию совместимости
6. Добавляет визуализацию на карточки
```

### 2. Расчет совместимости

Формула:
```
Общий балл = Совместимость знаков (30%) +
             Совместимость асцендентов (20%) +
             Гармония стихий (25%) +
             Планетарные аспекты (25%)
```

### 3. Отображение на карточках

На каждой карточке профиля:
- Бейдж с процентом совместимости (вверху справа)
- Полная карточка совместимости (внизу)
- Детальный анализ по сферам
- Информация о знаках зодиака и асцендентах

## 🔧 Настройка

### Требования к данным профилей

API должен возвращать профили с полем даты рождения:

```javascript
{
  date_naissance: "1994-05-15"  // Основное поле
  // Или альтернативные:
  // birth_date, birthday, date_of_birth
}
```

### Если даты рождения нет

Система использует fallback логику:
1. Вычисляет из поля `age` (середина года)
2. Использует тестовую дату (1995-01-01)

### Конфигурация API

Убедитесь, что в `.env` или Vercel настроены:
```
SPICE_API_KEY=ваш_ключ
SPICE_BASE_URL=https://dev2018.de5a7.com
```

## 🐛 Возможные проблемы и решения

### Проблема: Совместимость не отображается

**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь что скрипты загружены в правильном порядке
3. Проверьте что у пользователя есть дата рождения

### Проблема: Профили не сортируются

**Решение:**
1. Проверьте что `astro-matching-system.js` загружен
2. Убедитесь что профили содержат даты рождения
3. Проверьте лог в консоли: `[ASTRO-MATCHING]`

### Проблема: Неправильные проценты

**Решение:**
1. Проверьте формат дат (должен быть YYYY-MM-DD)
2. Проверьте матрицу совместимости в `astro-engine.js`
3. Убедитесь что знаки зодиака определяются правильно
