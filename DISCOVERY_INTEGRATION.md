# Discovery Preferences Integration

## ✅ Выполненная интеграция

Настройки Discovery Preferences из страницы settings теперь полностью интегрированы с функционалом discover страницы.

### 🔧 Реализованные функции:

#### 1. **Синхронизация настроек**
- Discovery Preferences из settings автоматически применяются на странице discover
- Настройки загружаются из API при инициализации discover страницы
- Поддержка обратной совместимости с локальными настройками

#### 2. **Обновленные API запросы**
- API запросы в discover теперь учитывают:
  - **Возрастной диапазон** (`age_from`, `age_to`)
  - **Гендерные предпочтения** (`sexe` параметр)

#### 3. **Автоматическое обновление**
- При изменении настроек в settings, discover страница автоматически:
  - Перезагружает настройки из API
  - Сбрасывает текущие профили
  - Загружает новые профили с обновленными фильтрами

#### 4. **Межвкладочная синхронизация**
- Изменения настроек синхронизируются между открытыми вкладками
- Используются события `storage` для уведомления об изменениях

### 📋 Маппинг настроек:

| Settings UI | API параметр | Discover использование |
|-------------|--------------|------------------------|
| Age Range (18-80) | `age_min`, `age_max` | `age_from`, `age_to` в search API |
| Show Men ☑️ | `cherche1 = 1` | `sexe = 1` в search API |
| Show Women ☑️ | `cherche1 = 2` | `sexe = 2` в search API |
| Show Couples ☑️ | `cherche1 = 3` | `sexe = 3` в search API |

### 🔄 Процесс работы:

1. **Инициализация discover**:
   - Загружаются настройки из API (`/api/discovery-preferences`)
   - Обновляются локальные переменные `ageSettings` и `discoveryPreferences`
   - Первый запрос профилей выполняется с учетом настроек

2. **Изменение настроек в settings**:
   - Настройки сохраняются через API (`POST /api/discovery-preferences`)
   - Отправляется событие обновления
   - Discover страница получает уведомление и перезагружает настройки

3. **Загрузка профилей**:
   - API запрос `/index_api/search` включает все фильтры
   - Профили фильтруются по возрасту и полу на стороне API

### 🎯 Результат:

- **✅ Полная интеграция**: Настройки из settings применяются к discover
- **✅ Реальное время**: Изменения применяются мгновенно
- **✅ API совместимость**: Использует правильные Spice API V2 endpoints
- **✅ Обратная совместимость**: Работает с существующими локальными настройками
- **✅ Межвкладочная синхронизация**: Настройки синхронизируются между вкладками

### 🚀 Использование:

1. Откройте **Settings** → **Discovery Preferences**
2. Измените настройки (возраст, пол)
3. Настройки автоматически сохранятся
4. Перейдите на **Discover** - новые настройки уже применены
5. Профили будут загружаться согласно вашим предпочтениям

### 📝 Технические детали:

- **API endpoint**: `/api/discovery-preferences` (GET/POST)
- **Spice API**: `/index_api/user/modify/wanttomeet` для сохранения
- **Search API**: `/index_api/search` с фильтрами
- **События**: `storage` events для синхронизации
- **Хранение**: Все настройки через API
